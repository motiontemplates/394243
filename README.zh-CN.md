## 关于 .motion

MP4 是成片；**.motion 是可复用的视频制作模板**，将动画工程、内容槽位、素材、依赖与说明组织在一起，让你用自己的内容再次制作。 [格式协议 ↗](https://motiongit.com/spec)

MotionGit 还提供素材匹配、生图、配音与配乐查找等配套能力，按实际槽位、账号权限和报价使用。
